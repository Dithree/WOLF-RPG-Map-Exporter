# WOLF RPG 地图导出工具 v1.0

一个完全离线的 **WOLF RPG Editor（ウディタ）地图导出工具**。无需打开编辑器即可把 `.mps` 地图渲染成 **PNG 图片**，并支持把地图层与事件层分开导出。

- 支持 **0x65 / 0x66 / 0x67** 三种地图格式混用
- 支持含日文/中文文件名的素材，可在非英文路径下运行
- 支持地图层 / 事件层 / 两者叠加三种导出模式
- 事件层可点选切换显示/隐藏（隐藏=半透明），导出/复制时隐藏事件不出现
- 墙角自动图块规则表（aid 感知），跨游戏通用

## 运行

```
python wolfrpg_map_gui.py
```

或使用打包好的 exe（见 Release）。

## 使用

1. 点击「选择游戏(Data 文件夹)」，选择游戏的 `Data` 目录（首次默认打开“此电脑”，之后记住上次路径）。
2. 左侧勾选要导出的地图，点击地图名可预览。
3. 底部选择导出模式：
   - **事件层（点事件切换显隐）**：只导出事件层（透明背景）
   - **地图层**：只导出地图层
   - **两者**：地图层 + 可见事件层叠加
4. 点击「导出当前地图」或「导出所选地图」导出 PNG。
5. 「复制到剪贴板」：可粘贴到 Word（图像）或文件夹（文件）。

## 目录结构

- `wolfrpg_map_gui.py` — GUI 主程序
- `offline_render_quadrant.py` — 离线渲染核心
- `offline_render_base.py` — 基础图块加载 / 多编码文件名解析
- `render_event_layer.py` — 事件层渲染
- `wolfrpg.py` / `wolfrpg_067.py` — `.mps` 0x65/0x66/0x67 解析
- `autotile_rule_norm.json` — aid 感知墙角规则表
- `mappings/` — 图块组映射
- `export_spawn.py` — 基于编辑器的 PNG 导出（唯一色提取用）
- `_rebuild_rule_table_aid.py` — 从唯一色参考图重建墙角规则表
- `_make_unique_all.py` — 生成唯一色素材
- 其它 `_*.py` — 调试/提取工具（见 `源码说明.md`）

## 说明

本工具为完全离线渲染，不依赖 WOLF RPG Editor 本体。渲染算法基于对引擎的反向工程，理论上适用于同一编辑器的所有游戏。
