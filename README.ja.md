# WOLF RPG マップ出力ツール v1.1

<p align="center">
  🌐 言語: <a href="README.md">中文</a> · <a href="README.en.md">English</a> · <b>日本語</b>
</p>

WOLF RPG Editor（ウディタ）のマップを、エディタを開かずに **PNG 画像**として出力できる完全オフラインのマップ描画/出力ツールです。**マップ層**と**イベント層**を分けて出力できます。

- 日本語・中国語のファイル名の素材に対応し、非英語パスでも動作
- アプリ内の言語切替: **中文 / 日本語 / English**（上部メニュー「言語」）
- **DeepSeek-v4-flash** が制作（作者は作業方針のみ提供）。ゲームマップの資料整理・記念保存などにどうぞ
- **夏拉** さんによる中国語エディタと資料収集に感謝
  - エディタ中文化スレッド: https://tieba.baidu.com/p/8466671485?fr=frs

**対応対象**: WOLF RPG Editor（ウディタ）製のゲーム。新エディタ（3.x、0x67 形式）と旧エディタ（2.x、0x65/0x66 形式）の両方に対応。

---

## 使い方

1. `WOLF_RPG_地图导出工具v1.1.exe` を実行。
2. 上部の **「ゲーム選択(Data フォルダ)」** をクリックし、ゲームの `Data` フォルダ（または `MapData` を含むフォルダ）を選択。
3. 左のマップ一覧で出力したいマップをチェック。マップ名クリックでプレビュー。複数チェック可能。
4. 下部で出力モードを選択:
   - **イベント層**: イベント層のみ出力（透明背景）。非表示にしたイベントは出力に含まれません
   - **マップ層**: マップ層のみ出力
   - **両方**: マップ層 + 表示中のイベント層
5. **「現在のマップを出力」** でプレビュー中のマップを出力。**「選択したマップを出力」** でチェックした全マップを選択フォルダへ一括出力。**「クリップボードにコピー」** で現在の結果をコピー。

## 更新履歴 v1.1

本ツールは完全なリバースエンジニアリングと多数の修正を経て完成しました:

### マップ形式解析
- `.mps` ファイル・3レイヤー・イベント領域を解析
- **0x65 / 0x66 / 0x67** の混在に対応（0x67 は LZ4 圧縮形式）

### タイル描画
- **base タイル**: raw=0 を有効な base タイル（1枠目）として描画。id32 等のタイル欠落を修正
- **aid1 透明レイヤー**: 100000~199999 は透明として描画しない
- **オートタイル行規則**: 8近傍マスク + 中央4桁でテーブル検索。任意レイヤー（0/1/2）に対応
- **角ルール（aid 対応）**: `aid;マスク;数字` でテーブルを区別し、壁の干渉や角が透明化する問題を修正

### レイアウト / サイズ
- **非正方形レイアウト修正**: `D[y][x]=flat[x*H+y]` を適用し、0x67 と 0x65/0x66 の非正方形マップのズレを修正
- 任意サイズの正方形マップ（10×10 / 20×20 / 30×30）も正しく描画

### 素材読み込み
- **多言語ファイル名解析**: 生バイトを保持し cp932 / shift-jis / utf-8 / gbk / big5 を試して実ファイルに一致。日本語・中国語名の文字化けを修正
- **非英語パス対応**: 全て Unicode パスで処理

### 背景 / レイヤー
- マップ背景画像に対応（手動設定テーブル。汎用性のためデフォルト無効）

### イベント層
- イベント層をオフライン描画（透明背景）。キャラ/タイルイベント・影に対応
- 実際の Data ディレクトリの `CharaChip`/`MapChip` 素材を使うようにしてイベント層の空白を修正
- プレビューでイベントをクリックして表示/非表示を切替（非表示=半透明）。出力時に非表示イベントは除外

## 補足

- 完全オフライン描画のため、WOLF RPG Editor 本体には依存しません。
- WOLF RPG Editor エンジンのリバースエンジニアリングに基づくため、原則として同一エディタの全ゲームに適用できます。
- 一部の特殊タイル・角が不正確な場合は、**ユニーク色出力 + 自動ルール収集**のフローで規則テーブルを拡充できます（詳細は `_rebuild_rule_table_aid.py`）。
